Tech Stack

Công nghệ cụ thể — không có lựa chọn thừa

Chọn theo tiêu chí: ship nhanh nhất, ít moving parts nhất, dễ scale khi có traction.

🖥️
Frontend
Next.js 14 (App Router)
Web + PWA — ship trước, mobile sau. Server Components cho tốc độ load. API routes tích hợp luôn, không cần backend riêng giai đoạn đầu.
Web-first PWA
Tailwind CSS + shadcn/ui
Component library sẵn có (Calendar, Sheet, Dialog). Không tốn thời gian build UI from scratch.
Nhanh
React Native + Expo (v2)
Mobile app sau khi web có traction. Dùng lại logic, chỉ viết lại UI layer. Expo Push Notifications tích hợp sẵn.
Phase 2+
⚙️
Backend
Supabase
Postgres + Auth + Realtime + Storage trong một. Row-level security cho multi-tenant. pg_cron cho scheduled jobs (sync, push, digest).
Postgres Auth Realtime
Next.js API Routes
Serverless functions, cùng repo với frontend. Xử lý Classroom sync, Stripe webhooks, push notifications. Không cần Express riêng.
Serverless
Upstash Redis
Cache daily conversation starters (tránh gọi Claude API lặp lại). Rate limiting Classroom API calls. Serverless-friendly, pay-per-request.
Cache
🤖
AI
Claude Sonnet 4.6
Tạo conversation starters + weekly digest. Ngữ cảnh dài, hiểu tốt context giáo dục. Dùng prompt caching cho system prompt cố định.
claude-sonnet-4-6
Prompt Caching
Cache system prompt (grade level, curriculum, tone) — TTL 5 phút. Giảm cost ~80% với repeated calls. Chỉ thay đổi phần topic trong user turn.
Cost −80%
Prompt structure
// System (cached) You are a parent conversation coach. Child: Grade 4, tone: playful Rules: simple words, curiosity-first, no jargon, max 15 words per question. // User (dynamic) Topic this week: "Ecosystems & food chains" Generate 3 dinner questions.
🔗
Integrations
Google Classroom API v1
OAuth 2.0, scope classroom.courses.readonly. Pull courses, coursework, submissions. Cần xin Google API approval trước (2–4 tuần).
⚠️ Xin approval sớm
Web Push + Expo Push
Web: Web Push API qua Vercel Edge. Mobile: Expo Notifications. Unified notification service — 1 API call, gửi cả web lẫn mobile.
Web iOS Android

Subscriptions
Pricing logic
Free: 1 con, 4 tuần, không có roadmap. Paid: không giới hạn con, roadmap đầy đủ, AI digest. Check plan bằng Supabase RLS + middleware.
Freemium
🚀

Vercel
Deploy Next.js. Edge Functions cho push notifications. Preview deploys cho mỗi PR. Analytics tích hợp sẵn. Free tier đủ dùng đến 10K users.
Hosting Edge

Managed Postgres. Tự động backup daily. Connection pooling với PgBouncer. Free tier: 500MB DB, 2GB bandwidth.

Rủi Ro Kỹ Thuật

3 rủi ro cần xử lý từ đầu

🔑
Google Classroom API Approval
Google yêu cầu review ứng dụng trước khi cho phép access Classroom data của user ngoài tổ chức. Quá trình này mất 2–4 tuần và có thể bị từ chối nếu không đáp ứng privacy policy requirements.
Nộp đơn ngày 1. Trong thời gian chờ, dùng test accounts trong G Suite domain riêng. Chuẩn bị privacy policy + demo video đầy đủ trước khi submit.
📊
Struggle Detection Cần Đủ Data
Thuật toán phát hiện tụt hậu cần ít nhất 3 tuần grade data để tính rolling average có ý nghĩa. User mới sẽ không thấy feature này ngay — có thể gây thất vọng.
Onboarding rõ ràng: "Lộ trình sẽ đầy đủ sau 3 tuần sync." Cho phép nhập điểm lịch sử thủ công trong tuần đầu để bootstrap data sớm hơn.
🏫
Trường Không Dùng Google Classroom
~40% trường K–12 tại Mỹ dùng Canvas, Schoology, hoặc PowerSchool thay vì Google Classroom. Phase 1 chỉ sync được Google Classroom — đây là giới hạn lớn cho TAM thực tế.
Manual add fallback phủ 100% ngay từ đầu. Roadmap v2: Canvas API + Schoology integration. Ưu tiên tuyển beta users từ các trường dùng Google Workspace for Education.
